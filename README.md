# Zheng Zhi Field Notes

A LessJS personal technical magazine and project lab.

The site uses the local LessJS framework source at `../src-tmp`, a custom
AppShell, static blog/project content, and a full-viewport oil-painting hero.

## Commands

```powershell
deno task generate:data
deno task build
deno task preview
```

## Routes

- `/`
- `/blog`
- `/blog/[slug]`
- `/projects`
- `/projects/[slug]`
- `/topics`
- `/about`
