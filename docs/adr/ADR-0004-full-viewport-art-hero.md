# ADR-0004: Full-Viewport Art Hero

## Status

Accepted

## Decision

The homepage starts with a 100vh full-bleed oil-painting technical still life hero.

## Rationale

The first screen should create a memorable author identity. Content appears after scroll so the hero
can work as an art-directed entry point instead of a crowded information panel.

## Consequences

Reading pages intentionally switch to a lighter editorial surface for usability.
