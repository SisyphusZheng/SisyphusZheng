# Visual System

## Palette

- Deep charcoal
- Warm ivory
- Muted teal
- Rust
- Brass gold
- Signal green

## Typography

- Serif for major editorial headings.
- Sans for navigation and interface labels.
- Mono for metadata, tags, and status.

## Surfaces

Homepage hero is cinematic and dark. Content pages are warm ivory with fine dividers and project-lab
status accents.
