# Design Target

Target: **Full-Viewport Oil Painting Technical Still Life Hero + Editorial Blog + Project Lab**.

The homepage creates the emotional signal. The lower sections and interior pages carry reading,
projects, topics, and release evidence.

## Rules

- No crowded hero cards.
- No default LessJS visual branding.
- No scroll hijacking.
- Reading pages prioritize typography and rhythm over visual spectacle.
- Project pages read like technical dossiers, not portfolio cards.
